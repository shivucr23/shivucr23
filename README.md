### 👨‍💻 About Me

I am an **Automotive Systems & Embedded Software Engineer** passionate about building robust, high-performance tooling for Electronic Control Units (ECUs), automotive communication stacks, and embedded cryptographic security.

- 🚗 **ECU Bootloader Engineering**: Deep expertise in ISO 14229 (UDS) flashing sequences, ISO 15765-2 (DoCAN) transport layers, CAN / CAN-FD communication, and flash driver integration.
- 🛡️ **Automotive Cybersecurity**: Implementing and validating hardware security specifications including AUTOSAR SecOC, HIS SHE v1.1, secure boot validation, and PKI certificate architectures.
- 🔬 **Firmware Memory Processing**: Building advanced binary manipulation workstations supporting Motorola S-Record, Intel HEX, and Volvo VBF with Vector HexView Table 3-3 checksum algorithms.
- ⚡ **Desktop Tooling**: Creating zero-dependency, single-file Windows executables that simplify automotive calibration and diagnostic testing.

### 🚀 Featured Engineering Projects

#### 🚗 [Automotive-ECU-Tools — Standalone Engineering Suite](https://github.com/shivucr23/Automotive-ECU-Tools)
A flagship suite of production-grade standalone desktop applications for automotive engineers:

* **🚀 Automotive UDS Download Tool (1.3.1)**:
  - Full ISO 14229 Diagnostic Session Control, Security Access (Seed & Key), and pipelined block flashing over CAN & CAN-FD.
  - Automated sequence runner with live bus monitoring and deterministic error recovery.
